# 纯前端 VP

基于 `algoux/rankland-web` 官方源码。直接使用原 `App.vue`、
`StyledRanklist`、`ScrollSolution`、主题服务和样式文件；重放与排名使用
`@algoux/standard-ranklist-utils` 的原有算法。

## 开发

```sh
pnpm install --frozen-lockfile
pnpm dev
```

只保留根路径，通过 URL 参数切换两个页面：

- `http://127.0.0.1:5174/`：分栏选赛配置。
- `http://127.0.0.1:5174/?contest=icpc2020invitational-xiaomi`：VP 榜单。

不注册 `/live/`、`/vp/`、`/collection/`、`/search/` 等额外页面路由，也不显示站点菜单栏。
榜单按当前可用屏宽分配列宽，所有题号同时可见；题目较多时会压缩队伍列、
单元格间距和字号，不需要横向滚动。队伍全名和提交详情仍可点击查看。

选赛页保留 RankLand 的配色和控件，按原合集的目录、名称和顺序逐列展开，
不插入年份目录、不重新分类。每列使用固定宽度，选择前后不伸缩。
顶部搜索覆盖名称、目录、年份和比赛 ID，
命中后自动展开完整路径。右侧为参赛配置；随机选赛限定在当前目录与搜索范围内。
支持面包屑返回，以及方向键在分栏间导航。

选中比赛后，目录和固定宽度的参赛配置之间显示弹性宽度的详细信息区。
学校 / 单位按源榜单名称去重；人数按队员名单统计，不假设每队人数；
金银铜使用官方 SRK 奖项分段算法统计。缺失的名单或奖项数据会明确标注，
并展示源数据提供的题目链接和相关链接。

纯前端入口为 `src/client/main.ts`，通过公开的跨域 API 读取合集和 SRK，
不需要启动 MySQL、Redis 和 Node.js 后端。

## 静态部署

```sh
pnpm build
pnpm preview
```

部署 `dist/`，以 `index.html` 为首页。应用只有 `/`，不需要额外路径的 SPA 回退规则。

## 使用边界

- 准确重放提供完整逐次提交记录的 ICPC、传统 CCPC 和 CCPC 2026 榜单；数据
  不完整会给出原因，不会虚构提交时间。积分赛和未知扩展赛制暂不支持。
- 支持跟随原赛制，或指定 ICPC / CCPC 2026。后者可设置通过队伍数和比例揭题阈值，
  使用官方 SRK 算法计算当前切片的揭题状态；封榜资格按 VP 时间判断。
- 可调参数：倍速、起始分钟和队伍名称，额外罚时固定为 20 分钟。参数随 URL 保存：
  `rule=auto|ICPC|CCPC26`、`speed`、`from`、`team`、`feed=0|1`、`count`、`ratio`。
  配置页开始一场比赛会生成新的 `run` 标识，避免覆盖其他场次的进度。
- 计时默认 1 倍速，可暂停或加速。计时状态和手动提交按比赛存储在浏览器
  localStorage；比赛运行中关闭页面，计时仍会继续。
- 「加入我的队伍」后在原 OJ 做题及判题，手动同步 AC / WA。本应用不执行代码判题。
- 「重新开始」会在确认后归零计时并清空该场的手动提交。
- 加载榜单需要访问 RankLand 及其文件 CDN。浏览器存储不可用时会显示提示。
